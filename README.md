# 線上訂單系統

專為飲料手搖飲設計的現代化線上訂購頁面，採用獨立的 HTML、CSS、JavaScript 模組化架構，無須任何建置打包工具即可直接運行，並能即時將訂單資料寫入指定的 Google 試算表。

---

## 📁 檔案結構說明

```text
drink_order_website/
├── index.html              # 訂購頁面主結構 (顧客資料、飲品列表、客製彈窗、購物車、成功通知)
├── style.css               # 專屬美化樣式表 (現代手搖飲風格、響應式 RWD、彈窗與動畫)
├── app.js                  # 核心前端邏輯 (CSV 解析、客製化規格計算、購物車與 Google API 對接)
├── google_apps_script.js   # Google 試算表後端程式碼 (自動產生流水號、時間、寫入訂購內容與金額)
├── menu_data.csv           # 飲品清單資料表 (類別、品名、中杯價格、大杯價格)
├── cutomize.csv            # 客製化規格資料表 (糖量、冰量、10元料、15元料)
└── README.md               # 系統說明與使用指南
```

## 🚀 試算表串接步驟 (只需 3 分鐘)

目標試算表網址：  
[https://docs.google.com/spreadsheets/d/1m0ykuSQNeCm08oBL8FxlDivDP5-AERAap1DSwuS-XTs/edit](https://docs.google.com/spreadsheets/d/1m0ykuSQNeCm08oBL8FxlDivDP5-AERAap1DSwuS-XTs/edit?usp=sharing)

### 第一步：打開 Google 試算表 Apps Script
1. 開啟上述試算表。
2. 點選頂端選單的 **「擴充功能」 (Extensions) -> 「Apps Script」**。

### 第二步：貼入後端程式碼
1. 將原本編輯器中的程式碼清空。
2. 開啟本專案目錄中的 **`google_apps_script.js`**，將全部內容複製並貼入編輯器中。
3. 點擊上方的 **「儲存」 (磁碟片圖示)**。

### 第三步：部署為網頁應用程式 (Web App)
1. 點擊右上角的 **「部署」 -> 「新增部署作業」**。
2. 點擊左側齒輪 ⚙️ 圖示，選擇 **「網頁應用程式」 (Web app)**。
3. 設定參數：
   - **說明**：`飲料訂單系統 API`
   - **執行身分**：`我 (您的帳號)`
   - **誰可以存取 (Who has access)**：務必選擇 **「所有人 (Anyone)」** *(若未選所有人，訪客下單時將無法寫入)*
4. 點擊 **「部署」**。
5. Google 會提示授權，依序點擊「核准存取權」-> 選擇帳號 ->「進階」->「前往專案 (不安全)」->「允許」。
6. 部署完成後，複製產生的 **「網頁應用程式網址 (Web App URL)」** (格式如：`https://script.google.com/macros/s/AKfycb.../exec`)。

### 第四步：綁定網址至訂購頁面
* **方式 A (免改程式碼)**：在瀏覽器打開訂購頁面，點擊右上角 **「試算表連線設定」**，將剛才複製的網址貼上並按「儲存設定」即可（會自動記錄於瀏覽器中）。
* **方式 B (永久預設)**：打開 `app.js`，將第 68 行的：
  ```javascript
  scriptUrl: localStorage.getItem("gas_web_app_url") || "請替換為您的Apps Script網址"
  ```
  填入您的部署網址。

## 📊 試算表寫入欄位規格

每次送出訂單時，後端腳本會自動排程加鎖 (`LockService`)，防止並發衝突，並依序寫入以下欄位：

| 欄位順序 | 欄位名稱 | 說明與格式範例 |
| :---: | :--- | :--- |
| **A** | **流水號 (主鍵)** | 自動產生唯一代碼，例如 `ORD-20261102-0001` |
| **B** | **訂購時間** | 台灣時區標準時間，例如 `2026/11/02 11:30:00` |
| **C** | **姓名** | 顧客所填寫的姓名 |
| **D** | **電話** | 顧客聯絡電話 (自動保留前綴 `0`) |
| **E** | **個人訂購內容** | 品項規格清單 (包含杯型、甜度、冰量、加料明細與小計) |
| **F** | **合計金額** | 整筆訂單總額，自動套用貨幣格式 `$#,##0` |
| **G** | **訂單備註** | 環保杯、送達時間或其他客製備註 |

## ✨ 頁面特色功能

1. **模組化分檔**：HTML、CSS、JS 各案獨立，代碼結構清晰易維護。
2. **自動 CSV 解析與容錯**：
   - 伺服器環境 (如 GitHub Pages) 自動以 `fetch()` 動態讀取 `menu_data.csv` 與 `cutomize.csv`，日後改動菜單只需編輯 CSV 檔案。
   - 本地檔案協議 (`file://`) 開啟時，自動啟用內建完整備用資料庫，避免跨域阻擋。
3. **客製化彈窗體驗**：
   - 自動判斷該飲品是否僅有中杯或大杯，不可選規格自動反灰禁用。
   - 甜度、冰量單選切換。
   - 加料區塊 (珍珠、仙草凍、綠茶凍 +10元；蜂蜜黑糖粉粿、荔枝椰果 +15元) 支援多選，金額即時累加計算。
4. **購物車與明細管理**：
   - 支援單品項購買或多人批次點餐加入購物車。
   - 即時數量增減、刪除品項、金額即時更新。
5. **CORS 與連線優化**：
   - 送出時採用 `text/plain` 格式跳過瀏覽器 OPTIONS 預檢，解決 Google Apps Script 常見的 CORS 跨域錯誤。
   - 訂單成功後彈窗顯示專屬流水號，並附上直達試算表查看的捷徑按鈕。
